# Job Checkmark

**Keep track of applications while browsing LinkedIn and Indeed.**

Job Checkmark is a published Chrome extension that marks applied jobs, surfaces salary information, and provides salary and location filters alongside the job search workflow.

[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/job-checkmark/dbgfnnldhiihniplgnidceafhhgbhldb) · [Watch the 48-second demo](https://www.youtube.com/watch?v=Eh8-5sHXulk) · [Portfolio](https://cashley104.github.io/CashleyData.github.io/#job-checkmark)

## What it does

- Marks jobs you have applied to on LinkedIn and Indeed.
- Displays salary information where available.
- Supports a minimum salary preference and hidden locations to focus the search.
- Stores application tracking data and preferences locally in the browser.

## Why I built it

Repeated job searches make it easy to revisit the same listings or spend time opening roles that do not match basic preferences. This project brings application status and useful listing information into the browsing workflow.

## Try it

1. Install the published extension from the Chrome Web Store.
2. Open LinkedIn or Indeed and browse job listings.
3. Use the extension's controls to manage tracked jobs and search preferences.
